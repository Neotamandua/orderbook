# Orderbook Crate

This crate serves as the implementation of the orderbook data structure and matching functionality.

## Usage

To use this crate in your project, simply include it as a dependency in your `Cargo.toml` file:

```toml
[dependencies]
orderbook = "0.1.0"
```

To see a simple external usage you can checkout tests/simple_integration or run it with:

``cargo test simple_integration``
